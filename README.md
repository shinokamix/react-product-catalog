# Product Catalog

Небольшое одностраничное приложение на React + TypeScript, которое показывает каталог товаров, позволяет фильтровать их по названию и открывать подробности в модальном окне.

## Что реализовано

- Главная страница с карточками товаров (изображение, название, цена)
- Поиск по названию в реальном времени
- Модальное окно с полной информацией о товаре:
  - большое изображение
  - описание
  - цена
  - кнопка «Купить»
- Закрытие модалки:
  - по кнопке `X`
  - по клику вне окна
  - по клавише `Esc`
- Загрузка данных из API: `https://dummyjson.com/products?limit=0`
- Обработка состояний загрузки и ошибки
- Адаптивная верстка для desktop / tablet (`<=768px`) / mobile (`<=480px`)

## Стек

- React
- TypeScript
- Vite
- CSS

## Запуск проекта

```bash
npm install
npm run dev
```
